How this was made

Bill titles and Congressional Research Service summaries come from the official GovInfo Bill Status bulk data. Text was turned into TF-IDF vectors and grouped with K-Means; topic names were assigned by hand after reading each group. The 2D layout uses t-SNE, so distances between far-apart groups are not meaningful. This map describes what bills are about. It does not rate or rank any member of Congress.
